# Rayvia

Rayvia — универсальный Windows-клиент для Xray.

## Скачать

**[Скачать Rayvia 0.4.0 — установщик Windows x64](https://github.com/m-amirov/RayVia/releases/download/v0.4.0/Rayvia-Setup-x64.exe)**

Страница релиза: [v0.4.0](https://github.com/m-amirov/RayVia/releases/tag/v0.4.0)

Установщик self-contained: отдельно устанавливать .NET не требуется.

## Изменения в 0.4.0

- усилен детерминированный handoff single-instance ownership для TUN и повышенного запуска;
- добавлены crash recovery, runtime state и безопасное восстановление System Proxy;
- добавлены проверка целостности Xray core, fail-closed updater и атомарное сохранение настроек;
- улучшены lifecycle connection state, cleanup Xray/System Proxy и снимок активного сервера;
- добавлены канонические идентификаторы серверов, миграция legacy-узлов и CI-проверки сборки.

## Исправление 0.3.1

- System Proxy теперь записывается в Windows как единый `127.0.0.1:PORT`, а не как строка `http=...;https=...`;
- адрес и порт корректно отображаются в «Параметры Windows → Прокси»;
- перед включением Rayvia сохраняет предыдущие системные proxy-настройки;
- при отключении предыдущие настройки восстанавливаются;
- если пользователь или другая программа изменили системный proxy после Rayvia, Rayvia не перезаписывает эти новые настройки;
- добавлена очистка некорректного значения, оставленного версиями до 0.3.1.

## Что изменилось в 0.3.0

0.3.0 — переработка структуры интерфейса и Smart Routing.

- главное окно уменьшено до 940 × 640 и остаётся фиксированным;
- навигация сокращена до пяти разделов: Главная, Профили, Маршрутизация, Активность, Настройки;
- подписки, серверы и группы объединены в «Профили»;
- Live Connections и журнал объединены в «Активность»;
- главная больше не выглядит как форма настроек: на ней остаются состояние, выбранный сервер, режим подключения и основные действия;
- System Proxy / TUN переключаются компактно на главной;
- список серверов оформлен как плотная таблица;
- добавление профиля и управление группами открываются только по запросу;
- исправлен Smart Routing для российских сайтов;
- удалена жёсткая зависимость от несуществующего `geosite:ru`;
- используется `geosite:category-ru`, а при его отсутствии Rayvia автоматически переключается на встроенные доменные правила;
- `.ru`, `.su` и `.рф` имеют встроенный DIRECT fallback;
- приватные сети идут DIRECT без зависимости от GeoIP-файла;
- если `geoip:ru` недоступен, подключение не падает: Rayvia продолжает работать по доменным правилам;
- сырой вывод Xray больше не показывается пользователю в MessageBox — технические детали остаются в журнале.

## Smart Routing

В режиме «Умная» правила применяются в следующем порядке:

1. пользовательские правила;
2. локальные и приватные сети → DIRECT;
3. российские IP через `geoip:ru` → DIRECT, если GeoIP доступен;
4. `geosite:category-ru` → DIRECT, если категория доступна;
5. домены `.ru`, `.su`, `.рф` → DIRECT независимо от GeoSite;
6. остальной трафик → PROXY.

Перед запуском Rayvia проверяет конфигурацию через `xray run -test`. Если встроенная GeoSite/GeoIP-категория недоступна, Rayvia автоматически пересобирает конфигурацию с fallback-правилами вместо остановки подключения.

## TUN

Rayvia использует встроенный TUN-inbound Xray и Wintun.

При первом подключении в TUN-режиме приложение запросит права администратора. Rayvia перезапустится с повышенными правами и продолжит подключение.

## Xray core

При первом подключении Rayvia загружает закреплённый релиз Xray (`v26.3.27`) из официального репозитория XTLS/Xray-core.
Перед распаковкой скачивается официальный asset `Xray-windows-64.zip.dgst`; SHA2-256 обязателен и проверяется до staging/install. При отсутствии или повреждении digest установка завершается fail-closed.

Файлы хранятся в:

`%LOCALAPPDATA%\Rayvia\Core`

## Диагностика

Журнал приложения и Xray доступен в разделе «Активность → Журнал».

Файлы логов:

`%LOCALAPPDATA%\Rayvia\Logs`

Если главное окно не удалось создать:

`%LOCALAPPDATA%\Rayvia\Logs\startup.log`

## Сборка

Требования:

- Windows;
- .NET 10 SDK.

```powershell
dotnet build src/Rayvia/Rayvia.csproj -c Release
```

Self-contained publish:

```powershell
dotnet publish src/Rayvia/Rayvia.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

## Данные

Настройки:

`%APPDATA%\Rayvia\settings.json`

URL подписки может содержать секрет. Не публикуйте `settings.json`.

Runtime recovery:

`%LOCALAPPDATA%\Rayvia\runtime-state.json`

На старте Rayvia проверяет stale runtime state и orphan `xray.exe`, принадлежащий только каталогу Rayvia, восстанавливает System Proxy по полному ownership state и удаляет runtime marker идемпотентно.
