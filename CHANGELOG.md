# Changelog

## 0.4.0

- добавлен детерминированный handoff single-instance ownership при запросе прав администратора для TUN;
- ownership handoff защищён arbitration protocol: competing экземпляры не могут перехватить mutex между parent и elevated child;
- добавлены crash recovery, runtime state marker и безопасное восстановление System Proxy;
- cleanup connection lifecycle теперь всегда пытается восстановить System Proxy и остановить Xray, сохраняя ошибки и recovery information при частичном сбое;
- добавлена проверка активной версии Xray core и целостности критических файлов;
- updater переведён на fail-closed проверку SHA-256 и атомарную установку;
- добавлены канонические идентификаторы серверов, миграция legacy-узлов и разрешение коллизий между подписками;
- добавлен immutable snapshot активного сервера и явная state machine подключения;
- настроены CI-gated Release/installer checks для self-contained Windows x64 сборки.

## 0.3.1

- исправлена запись Windows System Proxy: теперь используется `127.0.0.1:PORT`;
- устранено попадание `http=...` целиком в поле «IP-адрес» Windows;
- добавлено сохранение предыдущих системных proxy-настроек перед подключением;
- при отключении Rayvia восстанавливает исходные `ProxyEnable`, `ProxyServer` и `ProxyOverride`;
- Rayvia не перезаписывает proxy, если пользователь или другая программа изменили его после подключения;
- добавлена совместимая очистка некорректного proxy-значения из версий до 0.3.1.

## 0.3.0

- интерфейс перестроен вокруг пяти разделов: Главная, Профили, Маршрутизация, Активность, Настройки;
- окно уменьшено до 940 × 640 и остаётся фиксированным;
- подписки, серверы и группы объединены в «Профили»;
- соединения и журнал объединены в «Активность»;
- главная упрощена до статуса подключения, выбранного сервера и ключевых действий;
- System Proxy / TUN перенесены в компактный переключатель;
- серверы отображаются плотной таблицей вместо крупных карточек;
- добавление профиля и управление группами скрыты до явного вызова;
- исправлен Smart Routing: `geosite:ru` заменён на `geosite:category-ru`;
- добавлены встроенные DIRECT fallback-правила для `.ru`, `.su`, `.рф`;
- локальные сети больше не зависят от `geoip:private`;
- при недоступном `geosite:category-ru` Rayvia автоматически пересобирает рабочую конфигурацию;
- при недоступном `geoip:ru` Rayvia продолжает работать по доменным правилам;
- сырые ошибки Xray больше не выводятся пользователю: технические детали пишутся в журнал;
- README обновлён на установщик 0.3.0.
